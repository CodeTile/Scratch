Yes — in a .NET 10 app using **Fluent UI Blazor**, the usual way to make the **left navigation/menu dynamic** is to keep the menu items in state (a service or component property) and bind your nav UI to that list instead of hardcoding the links.

The exact implementation depends a bit on **which Fluent UI component you’re using for the left menu** (`FluentNavMenu`, `FluentTreeView`, custom sidebar, etc.), but the pattern is the same:

## The basic idea

1. **Create a menu item model**
2. **Store the current menu items in a service**
3. **Render the sidebar from that service**
4. **Update the menu list when the page/context changes**
5. **Notify the UI to re-render**

---

# 1) Create a model for your menu items

```csharp
public class NavMenuItem
{
    public string Text { get; set; } = "";
    public string Url { get; set; } = "";
    public string? Icon { get; set; }
    public bool Disabled { get; set; }
    public List<NavMenuItem> Children { get; set; } = new();
}
```

If your menu is simple, you may only need `Text` and `Url`.

---

# 2) Create a navigation state service

This service holds the current left-menu items and exposes a way to update them dynamically.

```csharp
public class NavigationMenuService
{
    public event Action? OnChange;

    public List<NavMenuItem> Items { get; private set; } = new();

    public void SetMenu(IEnumerable<NavMenuItem> items)
    {
        Items = items.ToList();
        NotifyStateChanged();
    }

    public void AddItem(NavMenuItem item)
    {
        Items.Add(item);
        NotifyStateChanged();
    }

    public void Clear()
    {
        Items.Clear();
        NotifyStateChanged();
    }

    private void NotifyStateChanged() => OnChange?.Invoke();
}
```

Register it in `Program.cs`:

```csharp
builder.Services.AddScoped<NavigationMenuService>();
```

---

# 3) Use the service in your layout / homepage sidebar

If your left menu lives in `MainLayout.razor`, inject the service there and render from it.

Example layout:

```razor
@inherits LayoutComponentBase
@inject NavigationMenuService MenuService
@implements IDisposable

<div class="layout">
    <div class="sidebar">
        <FluentNavMenu>
            @foreach (var item in MenuService.Items)
            {
                <FluentNavLink Href="@item.Url" Match="NavLinkMatch.Prefix">
                    @item.Text
                </FluentNavLink>
            }
        </FluentNavMenu>
    </div>

    <div class="content">
        @Body
    </div>
</div>

@code {
    protected override void OnInitialized()
    {
        MenuService.OnChange += Refresh;
    }

    private void Refresh()
    {
        InvokeAsync(StateHasChanged);
    }

    public void Dispose()
    {
        MenuService.OnChange -= Refresh;
    }
}
```

---

# 4) Change the menu dynamically from your homepage

In `Home.razor` (or whatever page controls the menu), inject the same service and set the menu items when needed.

```razor
@page "/"
@inject NavigationMenuService MenuService

<h3>Home</h3>

<FluentButton OnClick="ShowAdminMenu">Admin Menu</FluentButton>
<FluentButton OnClick="ShowUserMenu">User Menu</FluentButton>

@code {
    protected override void OnInitialized()
    {
        ShowUserMenu();
    }

    private void ShowUserMenu()
    {
        MenuService.SetMenu(new[]
        {
            new NavMenuItem { Text = "Dashboard", Url = "/dashboard" },
            new NavMenuItem { Text = "Profile", Url = "/profile" },
            new NavMenuItem { Text = "Orders", Url = "/orders" }
        });
    }

    private void ShowAdminMenu()
    {
        MenuService.SetMenu(new[]
        {
            new NavMenuItem { Text = "Admin Dashboard", Url = "/admin" },
            new NavMenuItem { Text = "Users", Url = "/admin/users" },
            new NavMenuItem { Text = "Settings", Url = "/admin/settings" }
        });
    }
}
```

When you click a button, the service updates the list, raises `OnChange`, and the sidebar re-renders automatically.

---

# 5) If you want the menu to change based on the current page

Instead of clicking buttons, set the menu in each page’s lifecycle method:

```razor
@page "/reports"
@inject NavigationMenuService MenuService

<h3>Reports</h3>

@code {
    protected override void OnInitialized()
    {
        MenuService.SetMenu(new[]
        {
            new NavMenuItem { Text = "Daily Report", Url = "/reports/daily" },
            new NavMenuItem { Text = "Monthly Report", Url = "/reports/monthly" },
            new NavMenuItem { Text = "Exports", Url = "/reports/exports" }
        });
    }
}
```

That gives you a **context-sensitive left menu** depending on the current section.

---

# Recommended structure for a real app

A clean setup is:

* **`MainLayout.razor`** → displays the left nav
* **`NavigationMenuService`** → stores current nav items
* **Pages/components** → call `MenuService.SetMenu(...)`
* Optional: **role-based logic** or **route-based logic** inside the service

---

# Example with nested menu items

If your left menu has expandable sections, use child items:

```csharp
MenuService.SetMenu(new[]
{
    new NavMenuItem
    {
        Text = "Administration",
        Children = new List<NavMenuItem>
        {
            new() { Text = "Users", Url = "/admin/users" },
            new() { Text = "Roles", Url = "/admin/roles" }
        }
    },
    new NavMenuItem
    {
        Text = "Reports",
        Children = new List<NavMenuItem>
        {
            new() { Text = "Sales", Url = "/reports/sales" },
            new() { Text = "Audit", Url = "/reports/audit" }
        }
    }
});
```

Then render recursively or with the Fluent UI component that supports hierarchy.

# Best practice for your scenario

If your **homepage needs to switch the left menu dynamically**, I’d use this pattern:

* Put the menu in **`MainLayout`**
* Store menu items in a **scoped `NavigationMenuService`**
* From the homepage, call `MenuService.SetMenu(...)`
* Subscribe to `OnChange` in the layout so the sidebar refreshes immediately

That’s the cleanest Blazor/Fluent UI approach.
